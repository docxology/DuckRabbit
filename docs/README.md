## Test software and preserve security/scientific boundaries

- [Testing and security boundaries](testing_philosophy.md): real computations,
  codecs, negative controls, native gates, and the limits of structural/replay QA.
- [Scholarship and evidence](scholarship.md): source tiers, offline snapshot
  lineage versus live identity, bibliography coverage, and unresolved blockers.

Hashes bind bytes, replay binds trusted implementations, and rendered pages
require actual visual inspection. None establishes human perception, decoder
sandboxing, authenticated authorship, live scholarly identity, or publication
by itself. Synthetic outputs remain `human_data=false`.

## Prepare an authorized release

- [Publication procedure](publication.md): generation and native audit interface.
- [Public-release checklist](public-release-checklist.md): compatibility,
  dependency/security review, live scholarship, visual acceptance, source/output
  bindings, and tag/deposit/DOI sequencing.

A local build or passing `audit --release` does not mint a release. Existing
unresolved scholarly identities remain blockers; use dated evidence only for
the exact observation it records.
