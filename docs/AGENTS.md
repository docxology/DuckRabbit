# Documentation guidance

Project documentation must describe the current typed multimodal generator,
not the source exemplar. Keep claims scoped to deterministic stimulus
construction and clearly distinguish taxonomy status from observer-level
perceptual evidence.

Read [`agent_instructions.md`](agent_instructions.md) and
[`architecture.md`](architecture.md) before changing design documentation.
Keep commands runnable from the project root and link generated media under
`output/media/` or figures under `output/figures/`.
