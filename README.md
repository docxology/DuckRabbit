# DuckRabbit

DuckRabbit generates visual, auditory, temporal, and audiovisual stimuli from
typed Python requests. Requests with the same seed and parameters produce
identical canonical media. Export PNG, WAV, GIF, MP4, or NPZ and verify the
result against its manifest.

- [Get started](docs/quickstart.md) and generate a verifiable stimulus.
- [Browse the documentation](docs/README.md) for the API, media, and evidence.
- [Build the manuscript](docs/manuscript/README.md) from the current source.
